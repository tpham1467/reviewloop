# reviewloop milestones 1 and 1.5 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Python package and CI integrations that review GitHub and GitLab PRs (milestone 1) and Bitbucket Cloud
and Bitbucket DC PRs (milestone 1.5) with a sandboxed agent CLI, as specified.

**Architecture:** A step pipeline over one `RunContext`, ported in shape from the previous bot. Deterministic work
(diff, anchoring, state markers, posting) is Python. Reasoning goes through `AgentAdapter` implementations that
drive agent CLIs inside an isolated copy of the checkout. Platforms plug in through `VcsAdapter`.

**Tech Stack:** Python 3.11+, uv, hatchling, pydantic v2, Typer, PyGithub, python-gitlab, atlassian-python-api,
httpx (only where no SDK fits), PyYAML, pytest, ruff, pyright, MkDocs Material.

**Spec:** `docs/specs/2026-11-27-milestone-1-design.md`. Every task reads the spec section it names.

## Global Constraints

- Python `>=3.11`; CI matrix 3.11, 3.12, 3.13. `pyright` strict, `ruff` with the config from Task 0.
- English only in the repository. No text copied from any other review bot's code, prompts or skills.
- The core never calls an LLM API. The only network calls are the VCS SDKs, tracker clients, and the agent CLIs.
- Credentials come only from environment variables. No secret appears in logs, comments, JSON or SARIF output.
- Agent processes never receive VCS or tracker tokens and never run in the original checkout.
- Coverage of `src/` at least 85%. Every task adds tests under `tests/unit/` mirroring the module path.
- Conventional Commits. Each task ends with one commit on its own branch `task/<NN>-<slug>`.
- Comment markers are exactly `<!-- reviewloop:finding {json} -->` and `<!-- reviewloop:state {json} -->`.
- Exit codes: 0 success, 1 findings at or above `fail_on`, 2 infrastructure error.
- Skills at most 800 words per `SKILL.md`; rule files at most 600 words. No emoji anywhere in skills or rules.

## Review Focus

1. A diff with CRLF line endings, a file without trailing newline, or a renamed file with edits: anchoring must
   still find the quoted code. Test in Task 2 (`test_anchor_crlf_and_no_newline`, `test_anchor_renamed_file`).
2. A human edits or deletes the summary comment between runs: the next run must do a full review, not crash.
   Test in Task 3 (`test_parse_state_marker_tampered`) and Task 11 (`test_resolve_turn_missing_summary`).
3. An agent CLI that writes a file other than its output, or prints secrets: the step fails and no secret reaches a
   comment. Test in Task 6 (`test_verify_rejects_extra_write`) and Task 10 (`test_redact_secrets_in_body`).
4. Comment command from a user without write access, or on a fork PR: nothing runs. Test in Task 13
   (`test_command_from_reader_ignored`, `test_fork_pr_skipped_on_open`).
5. A suggestion whose replacement contains triple backticks: the rendered block must not break out. Test in Task 4
   and Task 5 (`test_suggestion_fence_longer_than_content`).

# models.py
class Severity(StrEnum): CRITICAL="critical"; HIGH="high"; MEDIUM="medium"; LOW="low"
class Side(StrEnum): NEW="new"; OLD="old"
class Finding(BaseModel):
    id: str | None = None            # assigned by Python when posted: "f-" + fp[:4]
    path: str; line: int; side: Side = Side.NEW
    severity: Severity; rule: str | None = None; category: str
    text: str; existing_code: str; cause_code: str | None = None
    suggestion: str | None = None; security: bool = False
class Anchor(BaseModel): path: str; line: int; side: Side; in_diff: bool
class User(BaseModel): id: str; username: str
class PullRequest(BaseModel):
    number: int; title: str; body: str; source_branch: str; target_branch: str
    head_sha: str; base_sha: str; author: User; is_fork: bool; web_url: str
class ThreadRef(BaseModel): id: str; note_id: str | None = None
class Reply(BaseModel): author: User; body: str; created_at: datetime
class Thread(BaseModel):
    ref: ThreadRef; path: str | None; line: int | None; body: str; resolved: bool
    replies: list[Reply]; marker: "FindingMarker | None"
class FindingMarker(BaseModel): v: Literal[1]; id: str; fp: str; sev: Severity; rule: str | None
class RunState(BaseModel): v: Literal[1]; sha: str; base: str; turn: int; open: list[str]
class EventKind(StrEnum): OPENED="opened"; COMMAND="command"; IGNORED="ignored"
class Command(StrEnum): REVIEW="review"; RECHECK="recheck"; HELP="help"
class Event(BaseModel): kind: EventKind; command: Command | None = None; actor: User | None = None; pr_number: int | None = None
class CoverageStatus(StrEnum): REVIEWED="reviewed"; FAILED="failed"; EXCLUDED="excluded"
class FileCoverage(BaseModel): path: str; status: CoverageStatus; reason: str | None = None

# errors.py
class ReviewloopError(Exception): ...          # exit 2
class AgentStepError(ReviewloopError): ...
class ConfigError(ReviewloopError): ...

# vcs/base.py: the Protocol exactly as spec 8.1, plus
    def read_file(self, path: str, ref: str) -> str | None
# agents/base.py
class AgentTask(BaseModel):
    step: str; prompt: str; skills: list[str]; workdir: Path; output_schema: type[BaseModel]
    timeout_s: int; model: str | None = None
class AgentResult(BaseModel): output: BaseModel; transcript_path: Path; duration_s: float
class AgentAdapter(Protocol):
    name: str
    def check_auth(self) -> None
    def run(self, task: AgentTask) -> AgentResult    # one CLI invocation; repair loop lives in agents/runner.py
# trackers/base.py
class Ticket(BaseModel): key: str; title: str; body: str; url: str
class TrackerAdapter(Protocol):
    def fetch(self, keys: list[str]) -> list[Ticket]
